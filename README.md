🛍️ E-commerce Frontend – NextBuy

📌 Descrição  
Este projeto foi desenvolvido com o objetivo de aprofundar conhecimentos em React, gerenciamento de estado global, consumo de API REST e organização de rotas utilizando o ecossistema TanStack.

A aplicação simula o fluxo real de uma loja virtual, com:

Listagem de produtos com paginação  
Página de detalhes do produto  
Carrinho de compras com persistência de estado  
Busca de produtos  
Gerenciamento de loading e cache com TanStack Query  
Layout moderno e responsivo  

O projeto aplica separação de responsabilidades entre UI, estado global e dados do servidor, utilizando cache inteligente para melhorar performance e experiência do usuário.

🛠️ Tecnologias utilizadas  
React  
Tailwind CSS  
shadcn/ui  
TanStack Router  
TanStack Query  
Zustand  
Consumo de API REST

npm run dev
